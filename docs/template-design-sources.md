## 반영 사항

- A4, 좌우 22mm 여백, 흑백 인쇄용 표와 구분 음영.
- 완료계와 완료내역서의 별도 페이지 구성.
- 과업수행계획서에 참여인력·산출물·품질·보안·보고계획 입력란 추가. 실제 담당자와 계약조건을 사용자가 입력해야 한다.
- 사용인감계의 실제 날인 공간 확보. 검사·검수 등 기관 담당자의 승인 사실은 자동으로 만들지 않는다.
- 붙임 목록을 문서별로 수정 가능하게 제공. 목록에 있다고 파일이 자동 첨부되거나 발급되는 것은 아니다.
- 품목별 공급가액과 세액은 원 단위 반올림(half-up), 합계는 행별 계산액을 합산한다. 현재 10% 과세 용역용이며 면세·영세율·기관별 절사 기준은 별도 대응이 필요하다.
- 계약금액과 내역 합계, 계약금액 초과 청구, 필수정보 누락 검사.

## 검증 범위와 제출 전 확인

PDF는 내부 문서 모델에서 생성한 미리보기이다. HWPX를 한컴 한글로 직접 렌더링한 결과는 아니므로 줄바꿈과 페이지 수가 완전히 동일하다고 보장하지 않는다. HWPX 패키지·XML·표 폭·날인 높이와 PDF 페이지 분리·A4·장문 분할은 자동 테스트로 확인한다. 실제 제출 전에는 한컴 한글에서 원본을 열어 인쇄 배치와 날인을 확인해야 한다.

공고의 지정서식, 계약조건, 별지·증빙 요구가 우선한다. 기본 양식만으로 모든 기관의 접수나 검수를 보장하지 않는다. 발급서류·세금계산서·보증서·인감증명서 등은 해당 발급 경로에서 별도로 준비한다.
